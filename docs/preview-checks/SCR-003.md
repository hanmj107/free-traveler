## 확인해야 할 항목

1. Section 순서: Header → Intro(3단계 안내) → 탭(항공편/숙소/동행 구하기) →
   여행정보 Form(좌: 입력, 우: 요약) → 찾기 Tip 3개 → [동행 구하기 탭] 동행 작성
   Form 또는 로그인 안내 → Footer
2. 항공편 탭: 필수값 미입력 시 버튼 비활성화, 유효 입력 후 클릭 시 확인 Dialog →
   "이동하기" 클릭 시 새 탭에서 외부 사이트가 열리는지
3. 숙소 탭: 항공편과 동일한 흐름 + 체크아웃이 체크인과 같은 날이면 오류가 뜨는지
4. 동행 구하기 탭:
   - 비로그인 상태에서 로그인 안내 카드 + 안전 안내 패널만 보이는지(작성 폼 없음)
   - 로그인 + 성인확인 완료 계정으로 실제 동행 작성 Form이 보이는지, 필수값
     검증·연락처 탐지·안전수칙 동의가 정상 동작하는지
   - 저장 성공 시 성공 안내 + `/mates` 이동 버튼이 보이는지
5. Mobile 뷰에서 Form 순서와 버튼 위치가 자연스러운지, 큰 빈 영역이 없는지
